# My MedBook

## Описание проекта
Этот проект представляет собой мобильное приложение для управления медицинскими данными. Оно позволяет пользователям хранить информацию о врачах, анализах, заключениях, а также управлять событиями в календаре. 

## Основные функции
- Хранение информации о врачах и их профилях.
- Управление медицинскими анализами и заключениями.
- Интеграция с календарем для планирования событий.
- Шифрование данных для обеспечения конфиденциальности.
- Удобный пользовательский интерфейс, разработанный с использованием Jetpack Compose.

## Используемые технологии
- **Языки программирования**: Kotlin
- **База данных**: SQLite с использованием Room и SQLCipher для шифрования.
- **UI**: Jetpack Compose для создания современного интерфейса.
- **Архитектура**: Модульная архитектура с разделением на слои (UI, Store, Repositories, Persistent Storage).
- **Шифрование файлов**: EncryptedFile и MasterKey для безопасного хранения медиафайлов.
- **Инструменты сборки**: Gradle

## Архитектура проекта
Проект построен на модульной архитектуре с разделением на следующие слои:
1. **UI (User Interface)**:
   - Отвечает за отображение данных и взаимодействие с пользователем.
   - Реализован с использованием Jetpack Compose.
   - Включает экраны для работы с врачами, анализами, заключениями и календарём.

2. **Store**:
   - Управляет состоянием приложения.
   - Использует ViewModel для связи между UI и бизнес-логикой.

3. **Repositories**:
   - Отвечают за доступ к данным.
   - Абстрагируют источник данных (локальная база данных, удалённый сервер и т.д.).
   - Синхронизируют данные между UI и Persistent Storage.

4. **Persistent Storage**:
   - Локальное хранилище данных.
   - Реализовано с использованием Room для работы с SQLite.
   - SQLCipher используется для шифрования базы данных.
   - EncryptedFile и MasterKey применяются для безопасного хранения медиафайлов.
